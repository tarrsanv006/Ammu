# AMMU - PERSONAL AI ASSISTANT

Ammu is a personal AI-powered voice assistant built using Python (currently works only in Ubuntu Linux). It can understand voice commands, performs daily tasks, remembers information, and interacts with Google services.

## Features
- 24/7 voice activation using "Ammu"
- AI-powered conversations
- Gmail, Google Drive, Docs, and Calendar integration
- Personal memory and activity tracking
- Reminders and task management
- Web search and information retrieval
- Ubuntu system automation
- Voice-only interaction

## Tech Stack
- **Language:** Python
- **Platform:** Ubuntu Linux
- **AI:** Gemini / OpenAI API
- **Database:** SQLite
- **Google Services:** Google APIs
- **Voice:** Speech-to-Text and Text-to-Speech

## Future Plans
- Android support
- Cross-device synchronization
- Offline capabilities
